DescriptionSet up SSH client config for the sandbox endpoint
Usagesbx setup ssh [flags]

Experimental

This command is experimental.

Experimental features are intended for testing and feedback as their functionality or design may change between releases without warning or can be removed entirely in a future release.

Description

Write a generated SSH config + known_hosts and include it from ~/.ssh/config so "ssh .sbx" connects with no prompts. Named app instances use "ssh .sbx-" instead. Re-run any time; it's idempotent.

No SSH client key is needed — authentication is handled by the daemon's Unix socket (OS user boundary) combined with an active Docker login. Sign in first (sbx login).
