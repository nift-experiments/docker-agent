DescriptionCLI for managing Docker Hardened Images

Description

command-line interface for administering Docker Hardened Images. It provides commands to browse the DHI catalog, mirror images into your organisations and manage customizations.

Subcommands

CommandDescription
docker dhi attestationView attestations for Docker Hardened Images
docker dhi authAuthenticate with Docker Hub
docker dhi catalogBrowse the Docker Hardened Images catalog
docker dhi customizationManage Docker Hardened Images customizations
docker dhi mirrorMirror Docker Hardened Images to your organization
