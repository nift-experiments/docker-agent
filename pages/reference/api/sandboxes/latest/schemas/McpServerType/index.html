McpServerType

Type: string

McpServerType identifies a gateway server integration style.

Values: unspecified: unspecified is not a concrete server type. remote: remote is an HTTP remote MCP server. container: container is a container-backed MCP server. stdio: stdio is a stdio-backed MCP server.
