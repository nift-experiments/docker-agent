host · required

Type: string

Domain name or domain glob without a URL scheme or port. Use the separate port field to restrict the target to one port.
All schema constraints and annotations

  "type": "string"

path · required

Type: string

Absolute HTTP path glob. * matches one segment and ** matches any depth, including the bare path.
All schema constraints and annotations
{
  "description": "Absolute HTTP path glob. `*` matches one segment and `**` matches any depth, including the bare path.\n",
  "examples": [
    "/repos/docker/**"
  ],
  "pattern": "^/",
  "type": "string"
}
