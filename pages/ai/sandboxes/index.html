Docker Sandboxes run AI coding agents in isolated environments on your machine or on Docker-managed cloud infrastructure. Use the sbx CLI to create and manage either kind of sandbox.

The sbx CLI and local sandbox compute are free to use, including for commercial work. Cloud compute uses a pay-as-you-go subscription. Model-provider charges are separate.

Organization admins can centrally manage sandbox network, filesystem, and MCP policies, for local sandboxes across developer machines. Available on a separate paid subscription.

Get started

Install the sbx CLI and sign in, then choose where to run your agent:

EnvironmentUse it forStart here
Local sandboxesWork with files and supported hardware on your machineGet started locally
Cloud sandboxesRun on Docker-managed compute without local virtualizationGet started in the cloud

The two environments have separate credentials, network policies, and lifecycle controls. See Compare local and cloud sandboxes before adapting a workflow.

To create and manage cloud sandboxes from your application, see Sandboxes API and SDK.
