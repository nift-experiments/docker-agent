There are several ways you can provide feedback on Docker Offload.

Quick survey

The fastest way to share your thoughts is to fill out this short Docker Offload feedback survey. It only takes a minute and helps the Docker Team improve your experience.

In-product feedback

On each Docker Desktop Dashboard view, there is a Give feedback link. This opens a feedback form where you can share ideas directly with the Docker Team.

Report bugs or problems on GitHub

To report bugs or problems, visit the Docker Desktop issue tracker.
