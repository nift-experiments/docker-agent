Docker Hardened Images can be accessed and managed through several interfaces. Choose the tool that fits your workflow.

Use Docker Hub

Browse the DHI catalog on Docker Hub to search repositories, inspect image metadata, and view SBOMs, CVEs, and attestations.

CLI

Install and use the docker dhi command-line interface to browse the catalog, inspect images, and manage mirrors from your terminal.

MCP server

Connect an AI assistant to the DHI catalog to search repositories, inspect images, retrieve SBOMs, and check CVEs using plain language.

Use the DHI Terraform provider

Use the DHI Terraform provider to manage mirrors and automate DHI configuration as infrastructure as code.

Use the DHI API

Query Docker Hardened Images data programmatically using the DHI GraphQL API.
